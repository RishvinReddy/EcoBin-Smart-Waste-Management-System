# Glossary of Terms

| Term | Definition |
| :--- | :--- |
| **CVRP** | Capacitated Vehicle Routing Problem. A routing algorithm that ensures a truck visits necessary nodes without exceeding its physical carrying capacity. |
| **OR-Tools** | An open-source software suite by Google used for solving combinatorial optimization problems. |
| **XGBoost** | eXtreme Gradient Boosting. A highly efficient machine learning algorithm used in this project for time-series fill forecasting. |
| **Wokwi** | A browser-based electronics simulator used to virtualize the ESP32 and ultrasonic hardware without needing physical components. |
| **ESP32** | A low-cost, low-power system on a chip microcontroller with integrated Wi-Fi and dual-mode Bluetooth. |
| **Haversine Formula** | An equation used to determine the great-circle distance between two points on a sphere given their longitudes and latitudes. Used to construct the routing distance matrix. |
