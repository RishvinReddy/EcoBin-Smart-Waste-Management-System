# Software Requirements

## 1. Operating System
- **Development:** Windows 11, macOS, or Ubuntu Linux.
- **Production:** Debian/Ubuntu Server (Dockerized).

## 2. Programming Languages
- **Backend & ML:** Python 3.10+
- **Frontend:** TypeScript / JavaScript (Node.js 18+)
- **Hardware Simulation:** C++ (Arduino framework)

## 3. Libraries & Frameworks
- **Backend:** FastAPI, Uvicorn, SQLAlchemy, Pydantic.
- **Machine Learning:** XGBoost, Scikit-Learn, Pandas, NumPy.
- **Optimization:** OR-Tools (`ortools`).
- **Frontend:** React 18, Vite, React-Leaflet, TailwindCSS / Vanilla CSS.

## 4. Development Tools
- **IDE:** Visual Studio Code.
- **Hardware Simulator:** Wokwi.
- **Containerization:** Docker & Docker Compose.
- **Version Control:** Git.
